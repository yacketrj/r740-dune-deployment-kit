# Backup Strategy — Layer 1 (Design) Audit Findings Register

**Date:** 2026-09-30 · **Subject:** `docs/superpowers/specs/2026-09-29-backup-strategy-design.md` · **Requirement:** Strict Requirement 20, Layer 1 · **Tracking:** issue #119

Eight independent, read-only reviewers (one per hat: Architect, Security Architect, GRC, Network, Cloud Security, UI/UX, DBA, QA) reviewed the design. Nothing was executed on the host. Raw totals: **8 Critical, 23 High, 22 Medium, 10 Low (63 findings)**. They consolidate into the 12 themes below (T1–T12), each filed as a GitHub issue. Every CRITICAL and HIGH theme must be resolved in the design before implementation (Requirement 20).

## Contradictions between hats, and how they were resolved

1. **Private key off the host (Security) vs. automated restore proof (QA, DBA).** The host cannot decrypt if it never holds the private key. Resolved with two proofs: automated pipeline tests use a throwaway test key; a real-key restore drill is an assisted monthly procedure (operator supplies the key, it is removed afterwards) with a reminder alarm if a drill is overdue.
2. **Post-encrypt self-check by decrypting (QA) vs. no private key on the host (Security).** Resolved: integrity is checked before encryption (`tar -tf`, `pg_restore -l`, size floor, sha256 manifest) and after transfer (bit-exact comparison), and content usability is proven by the drill.
3. **Append-only remote storage (Security, Cloud) vs. what OneDrive/SMB can enforce.** Neither can truly enforce append-only for a credential that can also delete. Resolved as layered mitigation (dedicated account, version history and recycle bin, desktop-side snapshots) plus an explicitly accepted residual risk.
4. **Plaintext staging (Security) vs. staging size (Architect).** Resolved together by streaming `vzdump --stdout | age`, which removes the staging copy.
5. **Restore test in dune-dev (original design) vs. no secrets in a lower-trust VM (Security) and version fidelity (DBA).** Resolved: the DB drill restores only the `.backup` into a throwaway Postgres container of prod's image tag; the VM drill runs on the hypervisor as a scratch VMID on a no-uplink bridge; secrets never enter dune-dev.
